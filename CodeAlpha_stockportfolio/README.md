
# Stock Portfolio Tracker

A simple Python program that allows users to create and calculate the value of a stock portfolio.

## Features

- Enter stock symbols
- Enter the number of shares
- Calculate the value of each stock
- Calculate the total portfolio value
- Save the portfolio summary to a text file
- Handles invalid stock symbols and non-numeric quantities

## Technologies Used

- Python
- Dictionaries
- Loops
- Functions
- File Handling
- Exception Handling

## Available Stocks
