# 🤖 ChatCode – Chatbot

A simple **Python-based chatbot** that interacts with users through the command line. The chatbot responds to common questions and messages using predefined responses.

This project was developed as part of my **CodeAlpha Python Programming Internship**.

## 📌 Features

* 💬 Interactive conversation with the user
* 🤖 Responds to common questions and greetings
* 🧠 Uses predefined responses
* ⌨️ Command-line interface
* 🚪 Allows the user to exit the conversation
* 🐍 Built using Python

## 🛠️ Technologies Used

* **Python 3**
* Conditional statements
* Functions
* Loops
* String handling

ChatCode: Hello! How can I help you?
